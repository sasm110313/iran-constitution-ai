# ⚖️ سامانه هوشمند تحلیل و تطبیق حقوقی قانون اساسی جمهوری اسلامی ایران
### Iran Constitution AI Legal Analysis & Search Engine

سامانه هوشمند تحلیل و تطبیق حقوقی قانون اساسی، ابزاری پیشرفته و پرسرعت برای پردازش، استعلام حقوقی موضوعی و بررسی مطابقت یا مغایرت مصوبات مجلس شورای اسلامی با اصول ۱۷۷ گانه قانون اساسی جمهوری اسلامی ایران است.

---

## 🌟 ویژگی‌های کلیدی سامانه

1. **ارزیابی پرسرعت و موازی (Parallel Evaluation):**
   - اسکن و پردازش هم‌زمان تمامی **۱۷۷ اصل قانون اساسی** در زیر ۲ ثانیه.
   - محاسبه دقیق درصد مطابقت حقوقی و درجه صراحت احکام بدون ایجاد توهم یا متن خروجی ساختگی.

2. **ماژول تخصصی بررسی مصوبات مجلس (ویژه شورای نگهبان):**
   - امکان وارد کردن متن مصوبه یا ماده‌واحده مجلس برای بررسی سریع اصول مرتبط و کشف مغایرت‌های احتمالی با قانون اساسی.

3. **دسته‌بندی و فیلترینگ بر اساس فصل‌های قانون اساسی:**
   - قابلیت فیلتر بر اساس فصل‌های ۱۴ گانه (حقوق ملت، قوه مقننه، قوه قضائیه، رهبری، اقتصاد و امور مالی و...).

4. **تولید و کپی گزارش رسمی حقوقی (Export & Print):**
   - قابلیت تولید خلاصه گزارش متنی جهت استفاده در مکاتبات رسمی حقوقی و نسخه چاپی بهینه.

5. **رابط کاربری رسمی و سازمانی:**
   - پالت رنگی رسمی (سرمه‌ای، سفید و مشکی)، کاملاً واکنش‌گرا (RTL) و مناسب سازمان‌ها و مراجع قانونی.

```text
├── app.py                   # سرور اصلی Flask و تعریف REST API

├── parse_constitution.py    # پارسر متن قانون اساسی به فرمت ساختاریافته JSON

│   └── constitution_fa.json # پایگاه کامل ۱۷۷ اصل قانون اساسی به همراه فصل‌ها
├── templates/
│   └── index.html           # رابط کاربری وب (داشبورد هوشمند)
└── venv/                    # محیط مجازی پایتون
```

## 🚀 راهنمای نصب و اجرا

### ۱. پیش‌نیازها
- Python >= 3.10

### ۲. ایجاد محیط مجازی و نصب وابستگی‌ها

```bash
# ایجاد محیط مجازی
python3 -m venv venv

# فعال‌سازی محیط مجازی (Linux/macOS)
source venv/bin/activate

# نصب پکیج‌های مورد نیاز
pip install flask httpx
```

### ۳. اجرای برنامه

```bash
python3 app.py
```

پس از اجرای برنامه، مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **`http://127.0.0.1:5000`**

## 📡 راهنمای استفاده از REST API

### ۱. استعلام حقوقی موضوعی یا بررسی مصوبه
- **Endpoint:** `POST /api/search`
- **Content-Type:** `application/json`

**نمونه درخواست (Body):**
```json
{
  "query": "حق انتخاب وکیل در دادگاه‌ها و فراهم کردن امکانات برای افراد ناتوان",
  "threshold": 0.60
}
```
